# 2.1 컴퓨터 구조의 큰 그림

## 컴퓨터가 이해하는 정보
- 컴퓨터가 이해할 수 있는 정보 ➡️ **데이터, 명령어**
- **데이터**
  - 있는 그대로의 정보
  - 명령어에 종속적인 정보, 명령의 대상, 명령어의 재료
  - 컴퓨터는 0과 1만으로 다양한 숫자와 문자 데이터를 표현
- **명령어**
  - 데이터를 활용하는 정보
  - 명령어를 실행하는 주체는 CPU, CPU가 명령어를 처리하는 순서는 명령어 사이클

## 컴퓨터의 핵심 부품
- CPU, 메모리, 캐시 메모리, 보조기억장치, 입출력장치
- **CPU**
  - 데이터와 명령어를 읽어 들이고, 해석하고, 실행하는 부품임.
  - **CPU의 레지스터**
    - 산술논리연산장치(ALU): 사칙 연산, 논리 연산과 같은 연산을 수행할 회로로 구성되어 있는 일종의 계산기
    - 제어장치(CU): 명령어를 해석헤 제어 신호라는 전기 신호를 내보내는 장치
    - 레지스터: CPU의 작은 임시 저장장치, 데이터와 명령어를 처리하는 과정의 중간값을 저장함. 명령어가 레지스터에 저장되기 때문에 중요한 구성 요소임.
- **메모리와 캐시 메모리**
  - 메인 메모리를 줄여서 메모리라고 말함. RAM과 ROM이 있지만 RAM을 지칭하는 경우가 더 많음. RAM은 휘발성 저장장치임.
  - **실행 중**인 프로그램을 구성하는 데이터와 명령어를 저장하는 부품임.
  - 메모리 속 데이터와 명령어는 **주소**로 정돈되어 있음.
  - 캐시 메모리는 CPU와 메모리 사이에 있는 메모리임. CPU가 조금이라도 더 빨리 메모리에 저장된 값에 접근하기 위해 사용하는 저장장치임.
- **보조기억장치**
  - 전원이 꺼져도 저장된 정보가 사라지지 않는 **비휘발성 저장장치**임.
  - 오늘날 컴퓨터에는 하드 디스크 드라이브와 플래시 메모리 기반 SSD임.
  - 보조기억장치는 보관할 프로그램을 저장하고 CPU가 보조기억장치에 보관하고 있는 프로그램을 실행하려면 메모리로 가져와야 함.
- **입출력장치**
  - 컴퓨터 외부에 연결되에 컴퓨터 내부와 정보를 교환하는 장치임.
  - 마우스, 키보드 같이 입력을 할 때 사용하는 장치가 입력장치이고 스피커, 모니터 같이 컴퓨터의 정보를 받기 위해 사용하는 장치가 출력장치임.
  - 보조기억장치와 입출력장치를 **주변장치**라고 통칭하기도 함.
- **메인 보드와 버스**
  - 앞에 말한 부품들을 고정하고 연결하는 기판을 **메인 보드** 혹은 **마더 보드**라고 부름.
  - 메인 보드에 연결된 부품들을 각자의 역할을 적절히 수행하기 위해 서로 정보를 주고 받음. 이때 정보를 주고 받는 통로를 **버스**라고 함.
  - 버스 중 핵심 부품들을 연결하는 **시스템 버스**가 제일 중요함.
