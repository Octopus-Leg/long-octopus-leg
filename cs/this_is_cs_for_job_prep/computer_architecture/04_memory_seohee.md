# 2.4 메모리

## RAM
- 전원을 끄면 저장하고 있던 데이터와 명령어가 날아가는 **휘발성 저장장치**임.
- CPU는 보조기억장치에 저장된 프로그램을 곧장 가져와 실행할 수 없어서 프로그램을 메모리에 복사해 와야 하기 때문에 RAM의 용량이 중요함.
- RAM은 `Random Access Memory`의 약자로, 임의 접근 메모리라고 함.
- **임의 접근**: 은 저장된 요소에 순차적으로 접근할 필요 없이 임의의 위치에 접근 가능한 방식임.
- **순차 접근**: 임의 접근의 반대 개념으로 순차적으로 접근하는 방식임.

### RAM의 종류
- **DRAM**
  - `Dynamic RAM`으로 저장된 데이터가 동적으로 변하는 특성을 의미함. 시간이 지나면 저장된 데이터가 점차 사라짐.
  - 그래서 DRAM은 데이터 소멸을 막기 위해 일정 주기로 데이터를 재활성화해야 함. 소비 전력이 낮고 저렴해서 DRAM을 메모리로 일반적으로 사용함.
- **SRAM**
  - `Static RAM`으로 저장된 데이터가 변하지 않는 RAM을 의미함.
  - 시간이 지나도 저장된 데이터가 사라지지 않는 RAM이지만, 전원이 공급되지 않으면 저장된 내용이 소실됨.
  - DRAM 보다 속도는 빠르지만, 소비 전력이 크고 가격이 비싸서 캐시 메모리 등에 사용됨.
- **SDRAM**
  - `Synchronous Dynamic RAM`은 클럭 신호와 동기화된 발전된 형태의 DRAM을 의미함.
  - 클럭 타이밍에 맞춰 CPU와 정보를 주고받을 수 있음.
- **DDR SDRAM**
  - `Double Data RATE SDRAM`은 대역폭을 넓혀 속도를 빠르게 만든 SDRAM을 의미함.
  - DDR SDRAM은 두 배의 대역폭으로 한 클럭당 두 번씩 CPU와 데이터를 주고 받을 수 있어서 SDRAM보다 전송 속도가 두 배 정도 빠름.
  - 흔히 보는 메모리는 DDR4 SDRAM으로 SDRAM보다 열여섯 배 넓은 대역폭을 가짐.
  

## 메모리에 바이트를 밀어 넣는 순서 - 빅 엔디안과 리틀 엔디안

- 메모리는 데이터를 바이트 단위로 저장하고 관리함. 바이트를 어떤 순서로 저장하는지에 따라 빅 엔디안과 리틀 엔디안으로 나눌 수 있음.

### 빅 엔디안(Big Endian)
- 낮은 번지의 주소에 상위 바이트부터 저장하는 방식임.
- 상위 바이트는 가장 큰 값이라고 생각해도 됨. 예를 들어 16진수 1A2B3C4D에 있는 가장 큰수는 1A임.
- 메모리에 낮은 주소 번지부터 1A, 2B, 3C, 4D 순으로 저장됨.
- 메모리 값을 직접 읽거나 디버깅할 때 숫자를 읽고 쓰는 순서와 동일해서 편리함.

### 리틀 엔디안(Little Endian)
- 낮은 번지의 주소에 하위 바이트부터 저장하는 방식임.
- 메모리에 낮은 주소 번지부터 4D, 3C, 2B, 1A 순으로 저장됨.
- 직접 읽고 쓰기는 불편하지만 수치 계산이 편리함.


## 캐시 메모리
- CPU의 연산 속도와 메모리 접근 속도의 차이를 줄이기 위한 저장장치임.
- CPU와 메모리 사이에 위치한 SRAM 기반의 저장장치임.
- 캐시 메모리는 CPU와 가까운 순으로 L1 캐시, L2 캐시, L3 캐시가 있음.
- 대체로 L1, L2 캐시는 코어 내부에, L3 캐시는 코어 외부에 위치함. ➡️ 멀티 프로세서의 경우 일반적으로 L1, L2 캐시 메모리는 코어마다 할당되고, L3 캐시는 여러 코어가 공유함.
- L1 캐시 메모리는 명령어만 저장하는 L1I 캐시와 데이터만 저장하는 L1D 캐시로 구분하기도 함.
- CPU는 L1, L2, L3 캐시 순으로 데이터를 검색함.

### 캐시 히트와 캐시 미스
- 캐시 메모리에는 CPU가 사용할 법한 것을 저장하는데 이 데이터가 실제로 사용되는 경우를 **캐시 히트**, 틀린 예측으로 데이터를 직접 가져와야 하는 경우를 **캐시 미스**라고 함.
- **캐시 적중률**: 캐시가 히트되는 비율을 말하고, 범용적으로 사용되는 컴퓨터의 캐시 적중률은 85~95% 이상임.

### 참조 지역성의 원리
- **시간 지역성**: CPU는 최근에 접근했던 메모리 공간에 다시 접근하려는 경향이 있음. ➡️ 변수에서 잘 보임.
- **공간 지역성**: CPU는 접근한 메모리 공간의 근처에 접근하려는 경향이 있음. ➡️ 배열에서 잘 보임.

### 캐시 메모리의 쓰기 정책과 일관성
- CPU가 캐시 메모리에 데이터를 쓸 때는 캐시 메모리에 새롭게 쓰여진 데이터와 메모리 상의 데이터가 일관성을 유지해야 함.
- **즉시 쓰기**: 캐시 메모리와 메모리에 동시에 쓰는 방법임.
  - 데이터를 쓸 때마다 메모리를 참고해야 하므로 버스의 사용 시간과 쓰기 시간이 늘어난다는 단점이 있음.
- **지연 쓰기**: 캐시 메모리에만 값을 써 두었다가 수정된 데이터를 한 번에 메모리에 반영하는 방법임.
  - 메모리와 캐시 메모리 간의 일관성이 깨질 수 있다는 위험을 감수해야 함.
