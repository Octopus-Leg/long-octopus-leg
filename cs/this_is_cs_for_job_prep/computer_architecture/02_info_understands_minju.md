## 2. 컴퓨터가 이해하는 정보

**정보 단위**

- **비트(bit)**: 0 또는 1을 나타내는 가장 작은 정보 단위로 N비트는 2ᴺ개 정보 표현 가능
- **바이트(byte)**: 8비트
- **워드(word)**: CPU가 한 번에 처리할 수 있는 데이터 크기로 현대 CPU는 32bit 또는 64bit

### 데이터 - 0과 1로 숫자 표현하기

- **2진법**: `0b1010`, `1010₍₂₎`로 표기하는 컴퓨터 내부의 기본 수 체계
- **16진법**: `0xA`, `A₍₁₆₎`로 표기하며 자릿수가 긴 2진수를 축약하는 데 활용됨 (MAC 주소, IPv6 주소 등)

소수는 **부동 소수점(floating point)** 방식인 `m × 2ⁿ` 꼴로 표현하며, **IEEE 754** 표준을 따름.

<img width="1334" height="462" alt="image" src="https://github.com/user-attachments/assets/e03a826e-0b2e-4ef9-b2a1-26e470b1ee43" />

- 가수는 정수부가 1로 통일된 **정규화한 수**로 저장되어, 1을 제외한 소수 부분만 저장됨.
- 지수는 **바이어스 값(2^(k-1) - 1)** 이 더해져 저장됨.
- 10진수 소수와 2진수 소수의 표현이 딱 맞아떨어지지 않을 수 있어 `0.1 + 0.2 ≠ 0.3`과 같은 오차가 발생함.

### 데이터 - 0과 1로 문자 표현하기

- **문자 집합(character set)**: 컴퓨터가 이해할 수 있는 문자들의 집합
- **문자 인코딩**: 문자를 0과 1로 변환하는 과정
- **문자 디코딩**: 0과 1을 문자로 변환하는 과정
- **코드 포인트**: 문자에 부여된 고유 값

**대표 인코딩 방식**

- **ASCII**: 7bit(+패리티 1bit)로 영문, 숫자, 특수문자 128개를 표현함. 한글 표현 불가
- **EUC-KR**: 한글 1글자에 2byte를 사용해 약 2,350개 한글을 표현함. '뷁', '뜸' 등은 표현 불가
- **Unicode**: 전 세계 언어와 이모티콘까지 포함하는 통일된 문자 집합
- **UTF-8, UTF-16, UTF-32**: 유니코드 코드 포인트를 인코딩하는 가변 길이 방식
- **Base64**: 이진 데이터까지 아스키 문자로 변환하며, 부족한 비트는 `=`로 패딩함. 이메일 첨부파일 전송에 사용됨.

### 명령어

명령어는 **연산 코드**와 **오퍼랜드**로 구성됨.

<img width="862" height="239" alt="image" src="https://github.com/user-attachments/assets/90542230-9c9a-4272-8bbb-77af0dac64b2" />

- 오퍼랜드에는 주로 메모리 주소나 레지스터 이름이 담기므로 **주소 필드**라고도 부름.

**연산 코드의 대표 유형**

- **데이터 전송**: MOVE, STORE, LOAD(FETCH), PUSH, POP
- **산술/논리 연산**: ADD, SUBTRACT, MULTIPLY, DIVIDE, AND, OR, NOT, COMPARE
- **제어 흐름 변경**: JUMP, CONDITIONAL JUMP, HALT, CALL, RETURN
- **입출력 제어**: READ(INPUT), WRITE(OUTPUT), START IO, TEST IO

**기계어와 어셈블리어**

- **기계어**: 0과 1로 표현된, CPU가 이해하는 언어
- **어셈블리어**: 기계어를 사람이 읽기 편하게 단순 번역한 언어
- CPU 종류(CISC, RISC 등)에 따라 명령어가 달라지므로, 인텔 CPU 실행 파일을 애플 CPU에 그대로 옮길 수 없음.

**명령어 사이클**

CPU가 명령어를 처리하는 정형화된 주기를 **명령어 사이클**이라 함.

- **인출 사이클**: 메모리의 명령어를 CPU로 가져오는 단계
- **실행 사이클**: CPU로 가져온 명령어를 실행하는 단계
- **간접 사이클**: 오퍼랜드에 메모리 주소가 명시된 경우, 메모리에 한 번 더 접근하는 단계
- **인터럽트 사이클**: 인터럽트 발생 시 처리하는 단계
