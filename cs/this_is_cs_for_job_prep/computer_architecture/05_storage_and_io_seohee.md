# 2.5 보조기억장치와 입출력장치

- **하드 디스크 드라이브**
  - 자기적인 방식으로 데이터를 읽고 쓰는 보조기억장치임.
  - 하드 디스크에 있는 둥그런 원판인 플래터, 헤드를 통해 데이터에 접근함.
- **플래시 메모리**
  - 전기적인 방식으로 데이터를 읽고 쓰는 반도체 기반의 저장장치임.
  - USB, SSD가 플래시 메모리 기반 저장장치임.

## RAID
- **RAID**: 데이터의 안전성 혹은 성능을 확보하기 위해 여러 개의 독립적인 보조기억장치를 하나의 보조기억장치로 사용하는 기술임.

### RAID 레벨
- **RAID0**
  - 데이터를 여러 보조기억장치에 단순하게 나누어 저장하는 구성 방식임.
  - 분산되어 저장된 데이터를 **스트라입**이라고 하고, 분산하여 저장하는 동작을 **스트라이핑**이라고 함.
  - 장점: 입출력 속도가 빠름.
  - 단점: 저장된 정보가 안전하지 않음. 디스크 하나에 문제가 생기면 디스크2, 3, 4에 저장된 데이터는 불완전해짐.
- **RAID1**
  - 완전한 복사본을 만들어 저장하는 구성 방식임. 미러링이라고도 함.
  - 장점: 복구가 간단하고 안전성이 높음.
  - 단점: 원본과 복사본 두 곳에 데이터를 써야 해서 RAID0보다 쓰기 속도가 느려지고, 복사본이 저장된 크기만큼 사용 가능한 용량이 적어짐.
- **RAID4**
  - 패리티 정보를 저장하는 디스크를 따로 두는 구성 방식임. 패리티란 오류를 검출할 수 있는 정보임.
  - 장점: RAID1에 비해 적은 하드 디스크로도 안전하게 데이터를 보관할 수 있음.
  - 단점: 패리티를 저장하는 장치에 병목 현상이 발생함. 모든 디스크에 데이터를 저장할 때마다 패리티를 저장하는 디스크에도 쓰기 작업을 해야 하기 때문임.
- **RAID5**
  - 패리티를 분산하여 저장하는 구성 방식임.
  - 장점: RAID4의 단점인 병목 현상을 보완할 수 있음.
- **RAID6**
  - 서로 다른 2개의 패리티를 두는 구성 방식임. 
  - 장점: 오류를 검출하고 복구할 수 있는 수단이 2개가 생긴 것과 같음.
  - 단점: 새로운 정보를 저장할 때 패리티를 2개 저장해야 해서 RAID5에 비해 쓰기 속도가 일반적으로 느림.

## 입출력 기법
### 장치 컨트롤러와 장치 드라이버
- **장치 컨트롤러**
  - CPU와 입출력장치 사이의 통신을 중개하는 중개자 역할의 하드웨어임.
- **장치 드라이버**
  - 장치 컨트롤러의 동작을 알고, 장치 컨트롤러가 컴퓨터 내부와 정보를 주고받을 수 있도록 하는 프로그램임.
  - CPU는 장치 컨트롤러마다 장치 드라이버라는 프로그램을 실행함.

### 입출력 작업을 수행하는 방법
- **프로그램 입출력**
  - 프로그램 속 명령어로 입출력 작업을 수행하는 방법임.
- **인터럽트 기반 입출력: 다중 인터럽트**
  - 인터럽트가 여러 입출력장치로부터 동시다발적으로 발생하는 경우에 CPU는 우선순위가 높은 인터럽트부터 먼저 처리하게 됨.
  - 다중 인터럽트를 처리하기 위해서는 `프로그래머블 인터럽트 컨트롤러(PIC)`라는 하드웨어가 사용됨.
  - PIC는 여러 장치 컨트롤러에 연결되어 있어 장치 컨트롤러에서 보낸 하드웨어 인터럽트 요청들의 우선순위를 판별한 뒤, CPU에 처리해야 할 인터럽트를 알려주는 장치임.
  > PIC가 무시할 수 없는 인터럽트인 NMI까지 우선순위를 판별하지 않음.
- **DMA 입출력**
  - 입출력 장치와 메모리 사이에 전송되는 모든 데이터가 반드시 CPU를 거치면 CPU 부담이 커지기 때문에 CPU를 거치지 않고도 입출력장치와 메모리가 상호작용할 수 있는 `DMA`가 등장함.
  - DMA는 `Direct Memory Access`의 약자로 직접 메모리에 접근할 수 있는 입출력 기능을 말함.
  - DMA 입출력을 위해서는 시스템 버스에 연결된 DMA 컨트롤러라는 하드웨어가 필요함.
  - DMA 컨트롤러는 시스템 버스에 연결되고, 입출력장치들의 장치 컨트롤러는 입출력 버스라는 입출력 장치 컨트롤러의 전용 버스에 연결됨.
  - **과정**
    1. CPU -> DMA 컨트롤러에게 입출력 작업 명령함.
    2. DMA 컨트롤러가 장치 컨트롤러와 상호작용해 입출력 작업을 수행함.
    3. 입출력 작업이 끝나면 DMA 컨트롤러가 CPU에게 인터럽트를 걸어 알림.
> ✚ 책에는 추가적으로 입출력 버스인 PCIe 설명이 있음.
