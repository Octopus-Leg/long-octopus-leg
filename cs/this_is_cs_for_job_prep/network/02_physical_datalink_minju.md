## 2. 물리 계층과 데이터 링크 계층

### 이더넷

**이더넷(Ethernet)** 은 통신 매체를 통해 신호를 송수신하는 방법, 데이터 링크 계층에서 주고받는 데이터(프레임) 형식 등이 정의된 기술임. 현대 대부분의 (유선)LAN은 이더넷을 기반으로 구현되어 있음.

#### 이더넷 표준

이더넷은 **IEEE 802.3** 이라는 이름으로 국제 표준화된 기술임. IEEE 802.3은 엄밀히 말해 '이더넷과 관련된 다양한 표준들의 모음'에 가까움. `IEEE 802.3u`, `IEEE 802.3ab`처럼 숫자 뒤에 붙은 알파벳으로 버전을 나타냄.

| 이더넷 표준 | 알려진 이름 | 속도 |
|---|---|---|
| IEEE 802.3 | 이더넷 | 10Mbps |
| IEEE 802.3u | 고속 이더넷 | 100Mbps |
| IEEE 802.3z 또는 802.3ab | 기가비트 이더넷 | 1000Mbps |
| IEEE 802.3ae | 10기가비트 이더넷 | 10Gbps |
| IEEE 802.3ba | 100기가비트 이더넷 | 100Gbps |

1. 오늘날의 (유선)LAN 대부분이 이더넷 표준을 따르므로 대다수 LAN 장비들이 특정 이더넷 표준을 따름.
2. 이더넷 표준이 달라지면 통신 매체의 종류를 비롯한 신호 송수신 방법, 최대 지원 속도도 달라질 수 있음.

#### 이더넷 프레임

**이더넷 프레임(Ethernet frame)** 은 이더넷 기반 네트워크에서 주고받는 프레임을 말하며, 오늘날 주로 사용되는 이더넷 프레임은 Ethernet II 프레임이라고도 부름.

#### 프레임을 구성하는 5가지 정보

| 필드 | 크기 | 설명 |
|---|---|---|
| 프리앰블 | 8바이트 | 송수신 동기화용. 첫 7바이트는 `10101010`, 마지막 바이트는 `10101011` |
| 송/수신지 MAC 주소 | 6바이트 | 송/수신지 식별 |
| 타입/길이 | 2바이트 | 값이 1500(16진수 05DC) 이하면 크기, 1536(16진수 0600) 이상이면 타입 |
| 데이터 | 46~1500바이트 | 페이로드(상위 계층 데이터) |
| FCS | 4바이트 | 트레일러. 오류 검출용 CRC 값 |

- **MAC 주소(mac address)**: 송신지/수신지를 특정하는 6바이트(48비트) 길이의 주소. 콜론(:)으로 구분된 12자리 16진수로 구성됨. (예: `ab:cd:ab:cd:00:01`) 물리적 주소라고도 하며, 네트워크 인터페이스마다 하나씩 부여됨. (NIC가 여러 개면 한 호스트가 여러 MAC 주소를 가질 수 있음)
- **타입/길이**: 타입에는 캡슐화된 상위 계층 프로토콜이 명시됨. (IPv4 → 16진수 0800, ARP → 16진수 0806)
- **데이터**: 최대 크기는 일반적으로 1500바이트 이하로 제한됨. 이 크기를 **MTU** 라고 부름. 더 큰 데이터를 포함하는 특별한 프레임은 점보 프레임(jumbo frame)이라고 함.
- **FCS(Frame Check Sequence)**: 프레임 오류 여부를 확인하는 필드로, **CRC(Cyclic Redundancy Check)** 값이 명시됨. 송신지와 수신지의 CRC 값을 대조해 오류 여부를 판단함.

### 유무선 통신 매체

#### 유선 매체 - 트위스티드 페어 케이블

**트위스티드 페어 케이블(twisted pair cable)** 은 구리선을 통해 전기적으로 신호를 주고받는 통신 매체로, 두 가닥(pair)씩 꼬아져 있는(twisted) 구리선이라 이런 이름이 붙음.

- 성능은 **카테고리(category)** 를 통해 알 수 있음. 'Category'의 앞글자를 따서 'Cat'으로 표기함. (예: Cat7, Cat8 또는 Cat.7, Cat.8)

| 특징 | Cat5 | Cat5e | Cat6 | Cat6a | Cat7 | Cat8 |
|---|---|---|---|---|---|---|
| 전송 속도 | 100Mbps | 1Gbps | 1Gbps | 10Gbps | 10Gbps | 40Gbps |

- 구리선은 주변 잡음(**노이즈**)에 취약함. 잡음을 감소시키기 위해 그물 모양의 철사나 포일로 감싸는 방식을 **차폐(shielding)** 라고 함.
- **브레이드 실드(braided shield)**: 차폐에 사용된 그물 모양 철사 / **포일 실드(foil shield)**: 차폐에 사용된 포일

| 케이블 | 차폐 방식 |
|---|---|
| **STP(Shielded Twisted Pair)** | 브레이드 실드로 노이즈 감소 |
| **FTP(Foil Twisted Pair)** | 포일 실드로 노이즈 감소 |
| **UTP(Unshielded Twisted Pair)** | 아무것도 감싸지 않은 구리선 |

> **실드의 상세한 표기**: `[ ]/[ ]TP` 형식으로 표기하기도 함. 괄호 안에는 U(실드 없음), S(브레이드 실드), F(포일 실드)를 명시할 수 있음. 첫 번째 괄호는 케이블 외부를 감싸는 실드, 두 번째 괄호는 꼬아 놓은 구리선을 감싸는 실드를 나타냄.
> - **S/FTP**: 외부는 브레이드 실드, 구리선은 포일 실드
> - **F/FTP**: 외부와 구리선 모두 포일 실드
> - **SF/FTP**: 외부는 브레이드+포일 실드, 구리선은 포일 실드
> - **U/UTP**: 아무것도 감싸지 않음

#### 무선 매체 - 전파와 WiFi

- 전파는 약 3kHz부터 3THz 사이의 진동수를 갖는 전자기파를 의미함. 진동수 **2.4GHz** 와 **5GHz** 정도는 알아 두는 것이 좋으며, 두 진동수 모두 와이파이를 사용할 때 주로 활용됨.
- **와이파이(Wi-Fi)** 는 `IEEE 802.11` 표준을 따르는 무선 LAN 기술임. `IEEE 802.11ax`, `IEEE 802.11ac`처럼 802.11 뒤에 붙는 알파벳으로 표준 규격을 구분하고, 와이파이 뒤에 붙는 숫자로 세대를 구분함.

| 세대 이름 | 표준 규격 |
|---|---|
| Wi-Fi 7 | IEEE 802.11be |
| Wi-Fi 6 | IEEE 802.11ax |
| Wi-Fi 5 | IEEE 802.11ac |
| Wi-Fi 4 | IEEE 802.11n |

- 주파수 대역이 겹치면 신호 간섭이 발생할 수 있음. 그래서 같은 대역을 사용하는 무선 네트워크를 구분하기 위해 **채널(channel)** 이라는 하위 주파수 대역으로 세분화됨.
- 예: 2.4GHz 대역에서 1, 6, 11번 채널의 주파수는 서로 중첩되지 않으므로 신호 간섭으로 인한 성능 저하가 발생하지 않음. 성능 저하를 방지하려면 신호가 중첩되지 않는 채널을 사용하는 것이 중요함.
> 여러 무선 통신 기기를 연결해 무선 네트워크를 구성하는 장비를 **AP(Access Point)** 라고 함. 무선 공유기가 대표적임.<br>
> AP를 중심으로 구성된 무선 네트워크는 서비스 셋(Service Set)이라 하고, 이를 식별하는 정보는 **SSID(Service Set Identifier)** 라고 함. 와이파이 이름으로 사용되는 정보가 SSID임.

### 네트워크 인터페이스: NIC

네트워크 상에서 노드와 통신 매체가 연결되는 지점을 **네트워크 인터페이스(network interface)** 라고 함. 네트워크 인터페이스마다 물리적 주소(MAC 주소)가 부여되고, **NIC(Network Interface Controller)** 라는 하드웨어가 네트워크 인터페이스 역할을 담당함.

- NIC는 네트워크 인터페이스 카드, 네트워크 어댑터, LAN 카드, (이더넷의 경우)이더넷 카드 등 다양한 명칭으로 불림.
- 통신 매체의 신호를 호스트가 이해하는 프레임으로 변환하거나 그 반대로 변환하는 역할을 수행함. 때로는 MAC 주소를 토대로 잘못 전송된 패킷이 없는지 확인하기도 함.
- NIC의 동작은 입출력 방식과 동일함. 시스템 콜이 호출되면 (커널 모드로 전환된 뒤)송수신이 수행되고, 완료되면 인터럽트로 CPU에 알림. 대부분 DMA도 지원함.
- NIC의 지원 속도는 저마다 다르고, 이는 네트워크 속도에 큰 영향을 끼침. 고대역폭 환경에서는 메인 보드에 내장된 NIC가 있더라도 고가의 고속 NIC를 추가 구비하기도 함.
> 티밍(본딩)은 여러 물리적인 NIC를 하나의 고속 NIC처럼 구성하는 방식임. 티밍(teaming)은 윈도우, 본딩(bonding)은 리눅스에서 주로 사용하는 용어임.<br>
> 저성능의 여러 입출력장치를 하나로 묶어 사용한다는 점에서 RAID와 유사함. 하나의 NIC에 문제가 생겨도 다른 NIC로 송수신되어 안정적임.

### 허브와 스위치

허브와 스위치는 물리 계층과 데이터 링크 계층의 중간 노드임.

#### 물리 계층의 허브

- 허브는 물리 계층의 대표적인 네트워크 장비로, 여러 대의 호스트를 연결하는 장치임. **리피터 허브(repeater hub)** 또는 **이더넷 허브(Ethernet hub)** 라고도 부름.
- 케이블의 커넥터가 꽂히는 지점, 통신 매체를 연결하는 지점은 **포트(port)** 라고 함.

**허브의 2가지 특징**
1. 전달받은 신호를 **모든 포트로 내보냄**. 신호에 대한 어떠한 조작이나 판단도 하지 않음.
2. **반이중(half duplex) 모드** 로 통신함. 송신 또는 수신을 번갈아 수행하며, 동시 송수신이 불가능함. (무전기와 유사)

> **전이중(full duplex)**: 동시 송수신이 가능한 상태. 데이터 링크 계층 장비인 스위치가 지원함. (전화기와 유사)
> 허브는 반이중 모드이므로 어느 한 호스트가 정보를 전달하면 다른 호스트는 전송할 수 없음. 동시에 메시지를 보내면 **충돌(collision)** 이 발생하며, 충돌이 발생할 수 있는 영역을 **콜리전(충돌) 도메인(collision domain)** 이라고 함. 허브에서 충돌이 발생할 수 있는 영역은 '허브에 연결된 모든 호스트'가 됨.

#### 데이터 링크 계층의 스위치

**스위치(switch)** 는 허브의 한계를 보완하기 위한 네트워크 장비임. 허브와 달리 전달받은 신호를 **목적지 호스트가 연결된 포트로만** 내보내고, **전이중 모드** 를 지원하므로 콜리전 도메인이 좁음.

> 여기서 설명하는 스위치는 2계층(데이터 링크 계층)에서 사용한다는 점에서 L2 스위치라고도 부름. (책에서는 '스위치'를 L2 스위치와 동일한 의미로 사용)

- 스위치가 목적지 포트로만 내보낼 수 있는 이유는 **MAC 주소 학습(MAC address learning)** 기능이 있기 때문임.
   - 프레임 속 MAC 주소를 토대로 '포트, 연결된 호스트의 MAC 주소'의 대응 관계를 테이블로 메모리에 저장하는데, 이를 **MAC 주소 테이블(MAC address table)** 이라고 함.
- **VLAN(Virtual LAN)**: 가상(Virtual)의 LAN을 의미함. 같은 스위치에 연결된 모든 호스트를 하나의 네트워크로 간주하고 싶지 않을 때, 여러 논리적 네트워크로 나누고 싶을 때 사용됨.
   - 서로 다른 VLAN에 속하면 서로 다른 네트워크로 간주되며, 브로드캐스트 도메인도 겹치지 않음.
   - 서로 다른 VLAN의 호스트가 통신하려면 네트워크 계층 이상의 장비가 필요함.
