# 5.2 물리 계층과 데이터 링크 계층

## 이더넷
- LAN 내의 호스트들이 올바르게 정보를 주고받을 수 있도록 보장하는 유선 LAN의 핵심 기반 기술임. 
- 이더넷은 통신 매체 확정, 신호 송수신 방식, 데이터(프레임) 형식 등이 정의되어 있음.
### 이더넷 표준
- `IEEE 802.3`이라는 이름으로 국제 표준화가 이루어져 있으며, 제조사가 달라도 LAN 환경의 장비들이 서로 문제없이 호환되도록 만듦. 
- 표준의 버전은 '802.3' 뒤에 알파벳을 붙여 구분하고, 이더넷 표준이 달라지면 통신 매체의 종류를 비롯한 신호 송수신 방법, 최대 지원 속도도 달라짐.

#### 주요 이더넷 표준 규격

| 이더넷 표준 | 알려진 이름      | 지원 속도 |
| :--- |:------------| :--- |
| **IEEE 802.3** | 이더넷         | 10Mbps |
| **IEEE 802.3u** | 고속 이더넷      | 100Mbps |
| **IEEE 802.3z / 802.3ab** | 기가비트 이더넷    | 1000Mbps (1Gbps) |
| **IEEE 802.3ae** | 10기가비트 이더넷  | 10Gbps |
| **IEEE 802.3ba** | 100기가비트 이더넷 | 100Gbps |


### 이더넷 프레임
- 데이터 링크 계층에서 주고받는 데이터 단위임.

### 이더넷 프레임의 구성 요소

| 필드명                               | 구분 | 크기 | 특징 및 역할                                                                                                                                                  |
|:----------------------------------| :--- | :--- |:---------------------------------------------------------------------------------------------------------------------------------------------------------|
| **프리앰블**                          | 헤더 | 8바이트 | 송수신 장치의 **동기화**를 위해 사용되는 신호임. 첫 7바이트는 `10101010` 값을 가지며, 마지막 바이트는 프레임의 시작을 알리는 `10101011` 값을 지님.                                                         |
| **송수신지 MAC 주소**                   | 헤더 | 6바이트 | 송신지와 수신지 호스트의 물리적 주소임. MAC주소는 네트워크 인터페이스(NIC)마다 부여되는 고유한 물리적 주소이고, 12자리 16진수로 구성되어 있음. (예시) ab:cd:ab:cd:00:01                                            |
| **타입 / 길이**                       | 헤더 | 2바이트 | 해당 필드 값이 **1500 이하이면 길이**, **1536 이상이면 타입**을 나타냄. 타입은 상위 계층의 프로토콜 종류를 명시하며, 예를 들어 `0800`은 IPv4, `0806`은 ARP 프로토콜을 의미함.                                   |
| **데이터**                           | 페이로드 | 46~1500<br>바이트 | 상위 계층에서 전달받은 실질적인 데이터 본체임. 일반적인 이더넷 프레임이 수용할 수 있는 최대 데이터 크기를 `MTU (Maximum Transmission Unit)`라고 부르며 기본 값은 **1500바이트**임. 이를 초과하는 특별한 프레임은 `점보 프레임`이라고 함. |
| **FCS**<br>(Frame Check Sequence) | 트레일러 | 4바이트 | 프레임의 **오류 전송 여부를 확인**하기 위한 필드임. 송신측이 계산하여 명시한 `CRC` 값을 수신측이 재계산하여 대조한 뒤, 다르면 오류가 있다고 판단해 폐기함.                                                            |

## 유무선 통신 매체

### 유선 매체 — 트위스티드 페어 케이블
- 구리선 두 가닥씩(`pair`) 꼬아서(`twisted`) 만든 케이블임.
- 성능 등급인 **카테고리(Category, Cat)** 에 따라 지원 속도가 달라짐.
  - Cat5(100Mbps), Cat5e(1Gbps), Cat6(1Gbps), Cat6a(10Gbps), Cat7(10Gbps), Cat8(40Gbps)

#### 트위스티드 페어 케이블 노이즈 방지
- 트위스티드 페어 케이블은 구리선을 통해 전기적인 신호를 주고받아서 전기 신호에 왜곡을 줄 수 있는 주변 잡음인 **노이즈**에 취약함.
- **차폐**: 구리선 주변을 보호해 노이즈를 감소시키는 방식임.
- 케이블 내부의 잡음을 막기 위해 그물 모양의 철사망인 **브레이드 쉴드**나 알루미늄 호일인 **포일 쉴드**로 **차폐**를 함.
  - **UTP(Unshielded)**: 아무것도 감싸지 않고 구리선만 있는 형태임.
  - **STP(Shielded)**: 브레이드 쉴드로 감싸 노이즈를 감소시킨 케이블임.
  - **FTP(Foil)**: 포일 쉴드로 감싸 노이즈를 감소시킨 케이블임.


### 무선 매체 — 전파와 WiFi
- 주파수 대역($3\text{kHz} \sim 3\text{THz}$)의 전자기파를 이용한 무선 통신 기법임.
- 무선 LAN의 대표 격으로 `IEEE 802.11` 표준을 따르는 기술인 **와이파이**가 사용됨.
- 와이파이 역시 세대마다 표준 규격과 최대 지원 속도가 상이함.
  - Wi-Fi 4 (802.11n), Wi-Fi 5 (802.11ac), Wi-Fi 6 (802.11ax), Wi-Fi 7 (802.11be)
- 와이파이에서 주로 사용되는 주파수 대역은 $2.4\text{GHz}$ 혹은 $5\text{GHz}$임.
- **채널**
  - 무선 주파수 대역이 겹쳐 발생하는 신호 간섭을 방지하기 위해 하위 주파수 대역으로 잘게 쪼개놓은 단위임.
  - 주파수 중첩으로 인한 성능 저하를 방지하기 위해 간섭이 일어나지 않는 채널(예: 2.4GHz 대역의 1, 6, 11번 채널)을 선택하는 것이 중요함.
- **AP와 SSID**
  - 무선 공유기 같은 장비를 `AP(Access Point)`라고 하며, 이 AP가 구성하는 무선 네트워크의 식별 이름을 `SSID(Service Set Identifier)`라고 부름.
  - 흔히 말하는 와이파이 이름이 SSID임.


## 네트워크 인터페이스: NIC
- 네트워크 상에서 노드와 통신 매체가 연결되는 지점을 `네트워크 인터페이스`라고 함.
- 하드웨어적으로 이를 담당하는 장치가 **NIC**임. (랜카드, 네트워크 어댑터, 네트워크 카드 등)
- **동작 방식**
  - 패킷 송수신 시 NIC를 작동시키는 시스템 콜이 호출되면 커널 모드에서 송수진 작업을 수행한 뒤, 입출력이 완료되면 인터럽트를 통해 CPU에게 작업이 완료되었음을 알림.
  - DMA도 지원함.

## 허브와 스위치
- 허브와 스위치는 물리 계층 및 데이터 링크 계층의 연결을 돕는 중간 노드 장비임.

### 물리 계층의 허브
- 여러 대의 호스트를 포트를 통해 연결하는 물리 계층의 장치임. (리피터 허브, 이더넷 허브)
- 들어온 신호에 대한 어떠한 판단도 하지 않고, **연결된 모든 포트로 단순하게 신호를 내보냄**.
- **반이중 모드**: 송신과 수신을 동시에 수행하지 못하고 번갈아 가면서 수행해야 하는 무전기 방식 같은 **반이중 모드**임. 동시 송수신이 불가능하여 충돌의 위험이 있음.
  - 반이중 모드와 대비되는 통신으로 `전이중 통신`이 있음.
- **충돌 도메인(Collision Domain)**: 허브에 연결된 모든 호스트는 반이중 통신으로 인해 허브에서 충돌이 발생할 수 있는 영역임.

### 데이터 링크 계층의 스위치
- 허브의 한계를 보완하기 위한 데이터 링크 계층의 장비임.
- **MAC 주소 학습**: 프레임 속의 송신지 MAC 주소를 토대로 현재 몇 번 포트에 어떤 호스트가 연결되어 있는지 파악하여 `MAC 주소 테이블`에 기록함. 이 테이블을 참조하여 신호를 전체가 아닌 **목적지 호스트가 연결된 특정 포트로만 내보냄**.
- **VLAN**: 물리적으로는 같은 스위치에 연결되어 있어도 논리적으로 네트워크를 분리하는 기술임.
  - 서로 다른 VLAN에 속한 호스트들은 브로드캐스트 도메인 자체가 겹치지 않아 통신이 완전 차단되며, 상호 통신하려면 네트워크 계층 이상의 장비가 필요해짐.
