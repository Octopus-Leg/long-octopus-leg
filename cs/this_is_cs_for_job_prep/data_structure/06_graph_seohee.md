# 4.6 그래프

## 그래프의 종류와 구현

| 종류 | 정의 및 특징                                             |
| :--- |:----------------------------------------------------|
| **연결 그래프** | 그래프 상에 있는 임의의 두 정점 사이의 **경로가 항상 존재하는** 그래프를 의미함.    |
| **비연결 그래프** | 특정 정점 사이에 **경로가 존재하지 않는** 그래프임.                     |
| **방향 그래프** | 간선에 일정한 **방향성이 존재**하여, 정해진 방향으로만 이동할 수 있는 그래프임.     |
| **무방향 그래프** | 간선에 방향이 없어, 연결된 정점 양방향으로 자유롭게 이동할 수 있는 그래프임.        |
| **가중치 그래프** | 간선에 일정한 **가중치가 부여된** 그래프임. 가중치 값은 상황에 따라 음수일 수도 있음. |
| **서브그래프** | 부분 그래프임. 특정 그래프의 **정점과 간선의 일부분으로만 구성**된 그래프를 뜻함.    |

### 인접 행렬 기반 그래프 표현
- 그래프의 연결 관계를 **이차원 배열** $N \times N$ 형태로 표현하는 방식임.
- 여기서 $N$은 정점의 개수를 말하고, `<행, 열>` 값은 `<출발 정점, 도착 정점>`을 의미함.
- 두 정점이 연결되어 있으면 `1` (가중치 그래프라면 `가중치`), 연결되지 않았으면 `0`으로 표시함.
- 무방향 그래프를 표현한 인접 행렬의 특징은 행렬의 대각선 요소를 기준으로 연결 관계가 대칭을 이룬다는 점임.
- 정점 간의 연결 여부를 즉각적으로 확인할 수 있으나, 정점 수에 비해 간선이 적을 때는 메모리 낭비가 심함.

### 인접 리스트 기반 그래프 표현
- 그래프의 각 정점에 연결된 이웃 정점들을 **연결 리스트**를 기반으로 구현하는 방식임.
- 각 정점마다 하나의 연결 리스트를 가지며, 자신으로부터 나가는 간선 정보만 저장함.
- 가중치 그래프를 표현할 때는 하나의 노드를 표현하는 정보에 가중치 정보까지 포함하면 됨.
- 실제로 연결된 간선의 정보만 관리하므로 메모리를 효율적으로 사용할 수 있음.

## 깊이 우선 탐색과 너비 우선 탐색
### 깊이 우선 탐색(DFS)
- 그래프에서 더 이상 방문 가능한 정점이 없을 때까지 최대한 깊이 탐색하기를 반복하는 탐색 방법임.
- 깊이 우선 탐색에서 미방문 정점을 파악하기 위해 방문한 적이 있는 정점들을 `배열`로 관리하고, `스택`은 방문 중 뒤로가기가 필요할 때 사용함.

### 너비 우선 탐색(BFS)
- 최대한 넓게 탐색하기를 반복하는 방법으로, 인접한 모든 정점들을 방문하고, 그 정점들과 연결된 모든 정점들을 방문하기를 반복하는 탐색 방법임.
- 너비 우선 탐색에서 미방문 정점을 파악하기 위해 방문한 적이 있는 정점들을 `배열`로 관리하고, `큐`는 연결된 정점들을 저장하기 위해 사용함.

## 최단 경로 알고리즘
- **최단 경로 알고리즘**: 한 정점에서 목적지 정점까지 이르는 가중치의 합이 최소가 되는 경로를 결정하는 알고리즘임.
- 네트워크에서도 최단 경로 알고리즘이 사용되고, 대표적인 최단 경로 알고리즘으로 **다익스트라 알고리즘**이 있음.

### 다익스트라 알고리즘
- 간선의 가중치가 음수이면 사용할 수 없는 알고리즘이고, 특정 정점에서 다른 모든 정점까지의 최단 거리를 구해주는 알고리즘임.
- 특정 정점에 이르는 거리를 저장한 데이터가 최단 거리 테이블에 저장되어 사용됨.

```text
다익스트라 알고리즘 작동 순서

1️⃣ 최단 거리 테이블 상에서 시작 정점을 제외한 정점들은 모두 충분히 큰 수로 초기화
2️⃣ 시작 정점을 방문
3️⃣ 방문한 정점과 인접한 정점들을 탐색
4️⃣ 경로 상의 가중치 합과 최단 거리 테이블 상의 값을 비교
5️⃣ 최단 거리 테이블을 갱신할 수 있다면 갱신
6️⃣ 방문하지 않은 정점 중 최단 거리가 가장 작은 정점을 방문
7️⃣ 더 이상 방문할 정점이 없을 때까지 3~6의 과정을 반복하고 종료
```
