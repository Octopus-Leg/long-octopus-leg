# 4.3 스택과 큐

## 스택
- 한쪽 끝에서만 데이터의 삽입 및 삭제가 가능한 자료구조임.
- **주요 연산**:
  - **푸시**: 스택에 데이터를 **저장**하는 연산임.
  - **팝**: 스택에서 데이터를 **빼내는** 연산임.
- 나중에 삽입된 데이터가 먼저 나오는 **후입선출(LIFO, Last In First Out)** 구조임.

### 스택의 활용
- **함수 호출 관리**: 함수가 호출될 때 매개변수, 지역 변수, 복귀 주소 등이 스택 영역에 푸시됨. **최근에 호출된 함수가 가장 먼저 실행을 끝내고 반환**되므로, 가장 먼저 메모리에서 팝되어 삭제됨.
- **웹 브라우저 뒤로가기**: 방문한 URL을 스택에 푸시하고, 뒤로가기 버튼을 누를 때마다 팝하여 이전 페이지로 이동함.
- **미로 찾기**: 앞으로 이동할 때마다 경로를 스택에 푸시하고, 막다른 길에 마주쳐 되돌아갈 때 팝하여 직전 위치로 복기함.


## 큐
- 한쪽 끝에서는 데이터를 삽입하고, 다른 쪽 끝에서는 데이터를 삭제하는 자료구조임.
- **주요 연산**:
  - **인큐**: 큐의 한쪽 끝에 데이터를 **삽입**하는 연산임.
  - **디큐**: 큐의 반대쪽 끝에서 데이터를 **추출 및 삭제**하는 연산임.
- 먼저 삽입된 데이터가 먼저 나오는 **선입선출(FIFO, First In First Out)** 구조로, 흔히 '줄 세우기'에 비유됨.

### 큐의 활용
- **버퍼**: 데이터가 들어온 순서대로 차례차례 내보내거나 꺼내서 처리해야 하는 임시 저장 공간에 활용됨.

### 큐의 종류
- **원형 큐**: 큐의 처음과 끝(삽입 방향과 삭제 방향)을 하나로 연결하여 **원형으로 사용하는 구조**임.
- **덱**: 양방향 큐`double-ended queue`의 약칭으로, 데이터의 **삽입과 삭제가 양쪽 끝 모두에서 가능**하도록 확장된 큐임.
- **우선순위 큐**: 들어온 순서와 상관없이, 각 요소가 가진 **우선순위가 높은 순서대로 빠져나가는** 큐임. 주로 `힙`이라는 트리 기반 자료구조를 사용하여 효율적으로 구현함.
