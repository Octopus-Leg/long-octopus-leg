## 2. 배열과 연결 리스트

### 배열

- **배열(array)**: 일정한 메모리 공간을 차지하는 여러 요소들이 순차적으로 나열된 자료구조
- **인덱스(index)**: 0부터 시작하는 고유한 순서 번호. 인덱스로 배열의 요소를 식별함.

> RAM이 어떤 주소든 접근 시간이 일정한 것처럼, 배열도 인덱스를 통한 접근 시간이 요소의 개수와 무관하게 일정함.

| 연산 | 시간 복잡도 | 설명 |
|---|---|---|
| 접근 / 수정 | O(1) | 인덱스를 통한 임의 접근 가능 |
| 검색 | O(n) | 앞에서부터 순차적으로 탐색 (정렬되어 있지 않다고 가정함) |
| 삽입 / 삭제 | O(n) | 이후 요소들이 이동(재정렬)되어야 함 |

배열은 한 쪽 방향으로 요소가 나열되는 일차원 구조이지만, **이차원 배열**('배열 속에 배열'), **삼차원 배열**('배열 속 배열 속 배열')처럼 확장할 수 있음.

> **정적 배열과 동적 배열**
> - **정적 배열(static array)**: 프로그램 실행 전에 크기가 고정된 배열. 실행 도중 크기를 바꿀 수 없음.
> - **동적 배열(dynamic array)**: 실행 과정에서 크기가 변할 수 있는 배열. **벡터(vector)** 라는 이름으로 구현한 언어도 있음.

### 연결 리스트

- **연결 리스트(linked list)**: 노드의 모음으로 구성된 자료구조
- **노드(node)**: ① 저장하고자 하는 데이터(들)와 ② 다음 노드의 위치(메모리 상의 주소) 정보를 포함하는 연결 리스트의 구성 단위
- **헤드(head)**: 연결 리스트의 첫 번째 노드 / **꼬리(tail)**: 마지막 노드

> 모든 노드가 반드시 메모리 내에 순차적으로 저장되어 있을 필요가 없음. 그래서 **연속적으로 구성된 데이터를 불연속적으로 저장**할 때 유용함.

| 연산 | 시간 복잡도 | 설명 |
|---|---|---|
| 접근 / 검색 | O(n) | 헤드부터 순차적으로 접근할 수밖에 없음 |
| 삽입 / 삭제 | O(1) | 노드의 위치만 바꿔 저장하면 되어 재정렬이 불필요 |

#### 연결 리스트의 변형

- **싱글 연결 리스트(singly linked list)**: 노드가 '다음 노드'의 위치만 가리키는 기본 형태. 탐색이 단방향으로만 가능함.
- **이중 연결 리스트(doubly linked list)**: '다음 노드'뿐 아니라 '이전 노드'의 위치 정보도 포함해 양방향 탐색이 가능함. 단, 위치 정보 2개를 저장하므로 저장 공간이 더 필요함.
- **환형 연결 리스트(circular linked list)**: 꼬리 노드가 헤드 노드를 가리켜 원형으로 구성된 연결 리스트. 모든 노드를 여러 차례 순회해야 할 때 유용함.
