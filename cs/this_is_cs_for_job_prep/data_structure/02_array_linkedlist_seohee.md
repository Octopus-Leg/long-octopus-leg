# 4.2 배열과 연결 리스트

## 배열
- 일정한 메모리 공간을 차지하는 여러 요소들이 **순차적으로 나열된 자료구조**임.
- **인덱스**: 각 요소에 0부터 시작하여 부여되는 **고유한 순서 번호**이며, 이를 통해 각 요소를 식별함.
- **특징 및 연산 복잡도**:
  - `RAM`과 유사하게 인덱스를 바탕으로 특정 요소에 **접근 및 수정**하는 시간은 요소의 개수와 무관하게 $O(1)$로 일정함.
  - 요소가 $N$개일 때, 특정 데이터를 찾기 위해 차례대로 검사하는 **순차적 검색** 연산은 최고차항만 고려하여 $O(N)$이 됨.
  - 특정 요소를 **삽입하거나 삭제**하는 경우, 이후 모든 요소들을 재정렬해야 하므로 $O(N)$이 소요됨.
  - 1차원 구조뿐만 아니라 **이차원, 삼차원 배열** 등 다차원으로 확장이 가능하며, 관련 데이터를 일렬로 나열하여 관리할 때 활용도가 높음.
- **정적 배열과 동적 배열**:
  - **정적 배열**: 실행 전에 크기가 고정되어 **실행 도중에 크기를 변경할 수 없는** 배열임.
  - **동적 배열`Vector`**: 실행 과정에서 **크기가 동적으로 변할 수 있는** 배열임.

## 연결 리스트
- **노드의 모음**으로 구성된 자료구조임.
- **노드**: 저장하고자 하는 `데이터`와 `다음 노드의 위치(메모리 주소)` 정보를 함께 포함하는 구성 단위임.
- **주요 용어**:
  - **헤드**: 연결 리스트의 **첫 번째 노드**를 의미함.
  - **꼬리**: 연결 리스트의 **마지막 노드**를 의미함.
- **특징 및 연산 복잡도**:
  - 연속된 메모리 공간이 필요한 배열과 달리, 데이터를 메모리 상에 **불연속적으로 저장**할 수 있음.
  - **조회**: 특정 노드로 가려면 헤드부터 링크를 타고 순차적으로 접근해야 하므로 $O(N)$이 소요됨.
  - **추가/삭제**: 배열과 달리 요소를 이동하는 재정렬 과정이 불필요하며, 앞뒤 노드의 **위치 정보만 변경**하면 되므로 $O(1)$만에 가능함.

### 연결 리스트 종류
- **싱글 연결 리스트**
  - 노드가 **한 쪽 방향으로만** 꼬리에 꼬리를 무는 기본적인 형태임.
  - 특정 노드에서 다음 노드만 알 수 있고 이전 노드는 알기 어려워 **단방향 탐색**만 가능함.
- **이중 연결 리스트**
  - 노드 내에 다음 노드뿐만 아니라 **이전 노드의 위치 정보도 함께 포함**하는 구조임.
  - **양방향 탐색**이 가능하다는 장점이 있으나, 노드당 2개의 주소를 저장해야 하므로 **메모리 저장 공간이 더 많이 필요**함.
- **환형 연결 리스트**
  - **꼬리 노드가 헤드 노드를 가리키도록** 설정하여 노드들이 원형으로 구성된 구조임.
  - 모든 노드 데이터를 여러 차례 순회해야 할 때 유용하며, 이중 연결 리스트 형태로도 구현이 가능함.
