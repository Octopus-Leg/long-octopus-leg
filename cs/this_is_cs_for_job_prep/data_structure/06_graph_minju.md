## 6. 그래프

### 그래프의 종류와 구현

- **그래프(graph)**: **정점(vertex)** 이라 불리는 데이터를 **간선(edge, 링크)** 으로 연결한 형태의 자료구조. 네트워크, 운영체제 등 다양한 분야에서 범용적으로 사용됨.
> 트리도 사실 그래프의 일종임. 트리는 사이클을 형성하지 않고 연결된 노드 간에 상하 관계를 갖는 반면, 일반적인 그래프는 사이클을 형성할 수 있고 이웃한 정점끼리 상하 관계를 갖지도 않음.
> <br>**사이클(cycle)** 이란 특정 정점에서 출발해 다시 처음 출발했던 정점으로 되돌아오는 경로가 존재하는 경우를 말함.

간선이 어떤 형태로 정점을 연결하느냐에 따라 그래프의 종류가 나뉨.

- **연결/비연결 그래프**: **연결 그래프(connected graph)** 는 임의의 두 정점 사이의 경로가 존재하는 그래프. **비연결 그래프(disconnected graph)** 는 어떤 정점 사이에 경로가 존재하지 않을 수 있음.
- **방향/무방향 그래프**: 간선에 방향이 있으면 **방향 그래프(directed graph)**, 없으면 **무방향 그래프(undirected graph)**.
- **가중치 그래프(weighted graph)**: 간선에 가중치가 부여된 그래프. 가중치는 **비용(cost)** 이라고도 하며, 양수든 음수든 가능함.
- **서브그래프(subgraph)**: 특정 그래프의 정점과 간선의 일부분으로 이루어진 그래프.

**그래프의 구현**은 크게 2가지 방법이 있음.

| 표현 방법 | 기반 자료구조 | 설명 |
|---|---|---|
| **인접 행렬(adjacency matrix)** | 이차원 배열 | N×N 행렬의 〈행, 열〉 값으로 〈출발 정점, 도착 정점〉을 표현. 연결은 1(또는 가중치), 비연결은 0 |
| **인접 리스트(adjacency list)** | 연결 리스트 | 각 정점마다 연결 리스트를 가지며, 특정 정점에서 나가는 간선에 연결된 정점들을 노드로 삼음 |

> 무방향 그래프를 인접 행렬로 표현하면 대각선 요소를 기준으로 연결 관계가 대칭을 이룸. 가중치 그래프는 0/1 대신 가중치를 행렬·노드에 함께 표기함.

### 깊이 우선 탐색과 너비 우선 탐색

그래프의 모든 정점을 순회하는 대표적인 탐색 방법임.

#### ① 깊이 우선 탐색(DFS, Depth-First Search)

더 이상 방문 가능한 정점이 없을 때까지 **최대한 깊이 탐색**하기를 반복하는 방법. 구현에 다음 두 자료구조가 유용함.

- **배열**: 특정 정점의 방문 여부를 확인(미방문 정점 파악)하기 위해 사용.
- **스택**: 방문 중 **뒤로가기**가 필요할 때 사용.

#### ② 너비 우선 탐색(BFS, Breadth-First Search)

인접한 모든 정점을 방문하고, 방문한 정점들과 연결된 모든 정점을 방문하기를 반복하는 **최대한 넓게 탐색**하는 방법. 구현에 다음 두 자료구조가 유용함.

- **배열**: 특정 정점의 방문 여부를 확인하기 위해 사용함.
- **큐**: 특정 정점과 인접한 모든 정점을 줄 세우듯 저장하고, 다음 탐색 정점을 알기 위해 사용함.

> 동일한 그래프에서 정점 a부터 알파벳 순으로 탐색할 경우, DFS는 `a → b → e → c → f → d`, BFS는 `a → b → c → d → e → f` 순으로 순회함.

### 최단 경로 알고리즘

- **최단 경로 알고리즘**: 한 정점에서 목적지 정점까지 이르는 **가중치의 합이 최소**가 되는 경로를 결정하는 알고리즘. 지도 서비스의 최단 거리 안내, 컴퓨터 네트워크의 메시지 전송 등에 사용됨.
- **다익스트라 알고리즘(Dijkstra's algorithm)**: 간선의 가중치가 음이 아닌 수라는 가정 하에, 특정 정점에서 다른 모든 정점까지의 최단 거리를 구하는 알고리즘. 작동 과정에서 '특정 정점에 이르는 거리를 저장한 데이터'(최단 거리 테이블)가 함께 사용됨.

전체 동작 과정은 다음과 같음.

1. 최단 거리 테이블 상에서 시작 정점을 제외한 정점들은 모두 충분히 큰 수로 초기화함.
2. (시작) 정점을 방문함.
3. 방문한 정점과 인접한 정점들을 탐색함.
4. 경로 상의 가중치 합과 최단 거리 테이블 상의 값을 비교함.
5. 최단 거리 테이블을 갱신할 수 있다면 갱신함.
6. 방문하지 않은 정점 중 최단 거리가 가장 작은 정점을 방문함.
7. 더 이상 방문할 정점이 없을 때까지 3~6의 과정을 반복하고 종료함.
