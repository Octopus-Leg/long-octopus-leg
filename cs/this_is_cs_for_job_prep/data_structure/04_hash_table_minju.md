## 4. 해시 테이블

- **해시 테이블(hash table)**: 키(key)와 값(value)의 대응으로 이루어진 표(테이블)와 같은 형태의 자료구조. 키는 해시 테이블에 대한 입력, 값은 키를 통해 얻고자 하는 데이터임.
- **버킷(bucket)**: 키를 통해 얻고자 하는 데이터가 저장되는 공간. 여러 버킷이 배열을 형성함.
해시 함수에 키를 통과시켜 반환된 인덱스(버킷 배열의 인덱스)로 원하는 버킷에 접근함.

> **로드 팩터(load factor)**: 해시 테이블에 저장된 데이터 수를 버킷의 수로 나눈 값. 해시 테이블이 얼마나 가득 차 있는지에 대한 지표로, 로드 팩터가 클수록 성능이 떨어짐.

해시 테이블을 사용하는 이유는 **빠른 검색 속도** 때문임.

| 연산 | 시간 복잡도 |
|---|---|
| 검색 / 삽입 / 삭제 | O(1) |

속도가 빠른 만큼 상대적으로 많은 메모리 공간이 소모되며, **해시 충돌**이라는 문제도 해결해야 함.

### 해시 함수

- **해시 함수(hash function)**: 임의의 길이를 지닌 데이터를 고정된 길이의 데이터로 변환하는 **단방향 함수**. 단방향이므로 해시 값을 토대로 입력 데이터를 도출하기는 어려움.
- **해시 알고리즘(hash algorithm)**: 해시 함수의 연산 방법. 대표적으로 MD5, SHA-1, SHA-256, SHA-512, SHA3, HMAC 등이 있음.
같은 데이터라도 적용된 해시 알고리즘이 다르면 해시 값의 길이나 값이 달라지며, 입력 문자열이 한 글자만 달라져도 해시 값은 크게 달라짐.

해시 함수는 다음 용도로 활용됨.

- **데이터 무결성 검증**: 송신 측과 수신 측의 해시 값을 비교해 데이터 왜곡·훼손 여부를 파악함.
- **비밀번호 저장**: 단방향 암호화(해시 함수 적용)를 통해 저장하도록 규제됨. 대표적인 비밀번호 암호화용 해시 함수로 bcrypt, PBKDF2, scrypt, argon2 등이 있음.
> **모듈러 연산을 이용한 간단한 해시 함수**
> 키를 어떤 수(보통 해시 테이블의 크기)로 나눈 나머지를 해시 값으로 사용함. 키가 k, 테이블 크기가 m일 때 `h(k) = k mod m`. 단, 해시 충돌 가능성이 높아 실제 사용은 드묾.

### 해시 충돌

- **해시 충돌(hash collision)**: 서로 다른 키에 대해 같은 해시 값이 대응되는 상황. 대표적인 해결 방법으로 체이닝과 개방 주소법이 있음.
> 구글과 CWI 암스테르담 연구소는 서로 다른 두 PDF 파일(`shattered-1.pdf`, `shattered-2.pdf`)이 SHA-1 알고리즘에서만 동일한 해시 값을 도출한다는 것을 입증했음. 이 경우 두 파일을 같은 데이터로 판단하거나, 전송 중 데이터를 위조하는 보안상 위험이 발생할 수 있음.

**① 체이닝(chaining)**

충돌이 발생한 데이터를 연결 리스트로 추가하는 방법. 하나의 테이블 인덱스에 여러 데이터가 연결 리스트의 노드로 존재할 수 있음.

> 충돌이 발생할 때마다 노드가 추가되므로, 극단적으로 n개의 데이터가 모두 충돌하면 탐색 성능이 O(n)으로 떨어질 수 있음.

**② 개방 주소법(open addressing)**

충돌이 발생한 버킷의 인덱스가 아닌 다른 인덱스에 데이터를 저장하는 방법. 비어 있는 다른 버킷을 찾는 과정을 **조사(probe)** 라고 함.

- **선형 조사법(linear probing)**: 충돌 인덱스의 다음 인덱스부터 순차적으로 가용 인덱스를 찾음. `f(key) + 1, f(key) + 2, …`. 충돌 데이터가 몰려 저장되는 **군집화(clustering)** 문제가 있음.
- **이차 조사법(quadratic probing)**: 제곱수만큼 떨어진 거리의 인덱스를 찾음. `f(key) + 1², f(key) + 2², …`. 군집화를 완화하지만 제곱수의 규칙성으로 인해 근본적 해결은 어려움.
- **이중 해싱(double hashing)**: 다른 해시 함수(보조 해시 함수)에 대한 해시 값만큼 떨어진 인덱스를 찾음. `f(key) + g(key), f(key) + 2g(key), …`. 무작위로 인덱스가 생성되어 선형 조사법의 군집화 문제를 상당 부분 피함.

| 프로그래밍 언어 | 해시 테이블의 구현 |
|---|---|
| C++ | unordered_map |
| 자바 | HashTable, HashMap |
| 파이썬 | dictionary |
| 자바스크립트 | Map |
| Go | map |
