## 3. 동기화와 교착 상태

- **공유 자원(shared resource)**: 프로세스/스레드가 공유하는 자원. 메모리, 파일, 변수, 입출력장치 등.
- **임계 구역(critical section)**: 공유 자원에 접근하는 코드 중 동시에 실행되면 문제가 발생할 수 있는 코드
- **레이스 컨디션(race condition)**: 둘 이상의 프로세스/스레드가 동시에 임계 구역을 실행하여 자원의 일관성이 손상되는 문제

#### 동기화(synchronization)의 2가지 조건

- **실행 순서 제어**: 프로세스 및 스레드를 올바른 순서로 실행.
- **상호 배제**: 동시에 접근해서는 안 되는 자원에 하나의 프로세스/스레드만 접근.

### 동기화 기법

#### 뮤텍스 락(mutex lock)

- 상호 배제(MUTual EXclusion)를 위한 락(자물쇠)
- 임계 구역 진입 시 `acquire()`, 진입 후 `release()` 호출
- 자물쇠를 얻지 못한 프로세스는 자물쇠가 해제될 때까지 대기

```python
lock.acquire()
# 임계 구역
lock.release()
```

#### 세마포(semaphore)

- 공유 자원이 여러 개인 상황에서도 동기화가 가능한 일반화된 도구
- 변수 `S`(사용 가능한 공유 자원의 개수) + `wait()`(임계 구역 진입 전) + `signal()`(임계 구역 진입 후)

| 종류 | 설명 |
|---|---|
| 이진 세마포(binary semaphore) | S가 0과 1만 가짐. 사실상 뮤텍스 락과 유사 |
| 카운팅 세마포(counting semaphore) | S가 0과 1 이상의 값을 가짐. 일반적으로 '세마포'는 카운팅 세마포를 의미 |

#### 조건 변수와 모니터

- **조건 변수(condition variable)**: 실행 순서 제어를 위한 동기화 도구. 특정 조건 하에 프로세스/스레드를 중단·재개시킴.
  - `wait()`: 호출한 프로세스/스레드를 대기 상태로 전환
  - `signal()`: `wait()`로 일시 중지된 프로세스/스레드의 실행을 재개
- **모니터(monitor)**: 공유 자원과 그 자원을 다루는 함수(인터페이스)로 구성된 동기화 도구. 상호 배제와 실행 순서 제어 모두 가능함.
  - 모니터에 진입한 프로세스/스레드는 항상 하나뿐이며, 이미 진입자가 있으면 큐에서 대기함.
  - 자바의 `synchronized` 키워드가 모니터를 사용한 대표 예시

> **스레드 안전(thread safety)**: 멀티스레드 환경에서 어떤 변수/함수/객체에 동시 접근이 이루어져도 실행에 문제가 없는 상태. 레이스 컨디션이 발생하지 않음을 의미함.
> - 자바 예시: `Vector` 클래스의 `add` 메서드는 `synchronized` 적용 → 스레드 안전 / `ArrayList`의 `add` 메서드는 미적용 → 스레드 비안전

### 교착 상태

**교착 상태(deadlock)**: 일어나지 않을 사건을 기다리며 프로세스의 진행이 멈춰 버리는 현상

#### 교착 상태 발생의 4가지 필요 조건

| 조건 | 설명 |
|---|---|
| 상호 배제(mutual exclusion) | 한 번에 하나의 프로세스만 자원 이용 가능 |
| 점유와 대기(hold and wait) | 자원을 할당받은 상태에서 다른 자원 할당받기를 기다림 |
| 비선점(non-preemption) | 다른 프로세스의 자원을 강제로 빼앗지 못함 |
| 원형 대기(circular wait) | 프로세스와 자원이 원의 형태를 이루며 대기 |

- 4가지 조건이 **모두** 충족될 때 교착 상태 발생 가능성이 생김.

#### 교착 상태의 해결 방법

| 방법 | 설명 |
|---|---|
| **예방** | 4가지 필요 조건 중 하나를 충족시키지 않도록 함 |
| **회피** | 한정된 자원의 무분별한 할당으로 인한 문제로 간주, 자원을 신중히 분배함. 대표 알고리즘: **은행원 알고리즘(banker's algorithm)** |
| **검출 후 회복** | 교착 상태 발생을 인정하고 사후 조치. 자원 선점을 통한 회복 또는 프로세스 강제 종료 |
