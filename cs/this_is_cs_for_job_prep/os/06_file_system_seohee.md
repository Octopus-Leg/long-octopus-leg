# 3.6 파일 시스템

- **파일 시스템**: 보조기억장치의 정보를 파일 및 디렉터리의 형태로 저장하고 관리할 수 있도록 하는 운영체제 내부 프로그램임.

## 파일과 디렉터리
### 파일
- **파일**: 파일의 이름, 파일을 실행하기 위한 정보, 파일과 관련된 부가 정보로 구성되어 있음.
- **속성**: 파일과 관련된 부가 정보로 파일의 형식, 위치, 크기 등 파일과 관련된 다양한 정보를 말함. 메타데이터라고도 부름.
- 파일을 다루는 모든 작업은 운영체제에 의해 이루어짐. 응용 프로그램은 임의로 파일을 할당받아 조작하고 저장할 수 없고, 파일을 다루는 시스템 콜을 이용해야 함.
- **파일 디스크립터**: 저수준에서 파일을 식별하는 정보로, 0 이상의 정수 형태를 띠고 있음. 파일 핸들이라고 부르기도 함.
  - 운영체제는 프로세스가 새로 파일을 열거나 생성할 때 해당 파일에 대한 파일 디스크립터를 프로세스에 할당함.
  - 파일을 여는 데 사용되는 시스템 콜 `open()`은 파일 디스크립터를 반환함.
  - 파일 입출력을 위한 시스템 콜인 `write()`와 파일을 닫는 시스템 콜인 `close()`는 파일 디스크립터를 인자로 받음.

### 디렉터리
- 폴더라고 부르기도 하고, 오늘날의 디렉터리는 여러 계층을 가진 트리 구조 디렉터리로 관리됨.
- 루트 디렉터리라고 불리는 최상위 디렉터리는 `/`로 표현하고, `/`는 디렉터리 구분자로도 사용됨.
- **경로**: 디렉터리 정보를 활용해 파일 위치를 특정하는 정보를 말함.
- **디렉터리 엔트리**: 디렉터리에 속한 요소의 관련 정보는 테이블 형태로 표현되고, 이 테이블 형태로 표현된 정보의 행 하나하나를 말함.
  - 디렉터리 엔트리에는 파일의 이름과 파일이 저장된 위치를 유추할 수 있는 정보가 포함되어 있음.

### 파일 할당
- **블록**: 운영체제가 파일과 디렉터리를 읽고 쓰는 단위를 말함. 하나의 파일이 저장될 때는 하나 이상의 블록을 할당받아 저장됨.
- **연결 할당**: 각 블록의 일부에 다음 블록의 주소를 저장해 각각의 블록이 다음 블록을 가리키는 형태로 할당함.
- **색인 할당**: 파일을 이루는 모든 블록의 주소를 색인 블록이라는 블록에 모아 관리하는 방식으로 할당함.
  - 색인 할당을 사용하는 파일 시스템에서는 디렉터리 엔트리에 파일 이름과 함께 색인 블록 주소가 명시됨.


## 파일 시스템
- **포매팅**: 파일 시스템을 설정하여 어떤 방식으로 파일을 저장하고 관리할 것인지를 결정하고, 새로운 데이터를 쓸 준비를 하는 작업을 의미함.
  - 윈도우: NT 파일 시스템, ReFS 등
  - 리눅스: EXT, EXT2, EXT3 등
  - 맥OS: APFS
- 파일 시스템 EXT, EXT2 등에서는 아이노드라는 색인 블록을 기반으로 파일을 할당함.
- **아이노드**: 파일이 저장된 위치와 속성 등 파일의 이름을 제외한 파일의 모든 정보가 담겨 있는 색인 블록임.



### 아이노드 기반 파일 시스템
- 파일마다 각각의 아이노드를 가지고 있으며, 아이노드에는 각각의 번호가 부여되어 있음.
- EXT4 파일 시스템은 여러 블록의 그룹으로 이루어져 있음.
- **블록 그룹의 구성**
    
    | 이름 | 설명 |
    | :--- | :--- |
    | 슈퍼 블록 | 아이노드의 개수, 총 블록 개수, 블록 크기 등 전체적인 파일 시스템의 정보를 저장함. |
    | 그룹 식별자 | 블록 그룹에 대한 메타데이터를 저장함. |
    | 블록 비트맵 | 현재 블록 그룹 내에서 데이터가 어떻게 할당되었는지를 저장함. |
    | 아이노드 비트맵 | 현재 블록 그룹 내에서 아이노드가 어떻게 할당되었는지를 저장함. |
    | 아이노드 테이블 | 각 파일의 아이노드 정보를 저장함. |
    | 데이터 블록 | 각 파일의 데이터를 저장함. |
- 아이노드 기반 파일 시스템에서는 데이터 영역에 공간이 남아 있더라도 아이노드 영역이 가득 차 아이노드를 할당할 수 없다면 새로운 파일을 생성할 수 없음.

### 마운트
- **마운트**: 어떤 저장장치의 파일 시스템에서 다른 저장장치의 파일 시스템으로 접근할 수 있도록 파일 시스템을 편입시키는 작업을 의미함.
```shell
mount -t ext4 -o ro /dev/sda /mnt/test
```
- dev/sda 장치에 있는 ext4 파일 시스템을 읽기 전용으로 /mnt/test 디렉토리에 마운트하라는 명령어임.
